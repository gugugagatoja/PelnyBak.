# Godzina wyjścia

Prosty kalkulator godziny wyjścia z pracy: godzina przyjścia + czas pracy ± nadgodziny
(odbierane — wychodzisz wcześniej, dorabiane — zostajesz dłużej).

Całość to jeden plik `index.html` — działa w przeglądarce na telefonie i komputerze.
Ostatnie ustawienia zapamiętuje w przeglądarce (localStorage).
